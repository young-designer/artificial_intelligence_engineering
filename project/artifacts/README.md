# artifacts

Артефакты создаются командой:

```bash
python -m src.train
```

Содержимое:

- `model.joblib` — финальный sklearn pipeline;
- `model_metadata.json` — метаданные обучения, признаки, баланс классов, лучшая модель;
- `leaderboard.json` — сравнение моделей по метрикам;
- `sample_orders.csv` — несколько заказов для быстрой проверки структуры данных.

Если артефакты удалить, сервис попросит заново запустить обучение.
