# data

В папке лежит синтетический учебный датасет:

- `delivery_orders_synthetic.csv`

Он генерируется командой:

```bash
python -m src.train
```

Данные не содержат персональной информации. Каждая строка — заказ доставки с признаками маршрута, склада, курьера, условий доставки и целевой переменной `is_late_delivery`.
